# Portfolio

Personal portfolio of **Jona Firman**, a full-stack developer building SaaS products.

**Live:** https://jonafirman.vercel.app

## Tech Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing Content

All text (name, about, skills, projects) lives in [`src/lib/site.ts`](src/lib/site.ts). Edit that file to update the site; no component changes needed.

## Project Structure

```
src/
├── app/          # routes, layout, global styles
├── components/   # UI components
└── lib/site.ts   # site content
```
